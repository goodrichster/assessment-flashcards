Place question screenshots here for image-based flashcards.

Current sample card expects:
- ramp-angle-question.png

Practice Questions (tagged "Practice Questions" in the filter):
- Add PNGs to `imports/act_illustrated/` named `page_2.png`, `page_3.png`, etc., then run:
  `node scripts/import-practice-questions.js`
- The script copies those PNGs here and regenerates `data/practice-cards.js`.

Example path used by `app.js`:
- `images/ramp-angle-question.png`
- `images/page_2.png`, `images/page_3.png`, … (for practice cards)
